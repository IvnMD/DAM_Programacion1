# DAM_Programacion1

Repositorio de la asignatura **Programación 1** del ciclo formativo de grado superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**. Aquí se guardan las prácticas, proyectos, apuntes, exámenes y ejemplos de código utilizados en clase.

## Descripción

Este repositorio reúne el material completo usado en la asignatura de Programación 1:
- ✅ Ejercicios prácticos y evaluables
- 📚 Exámenes y simulacros
- 🎓 Proyectos formativos
- 📝 Guías y apuntes de teoría
- 🔄 Materiales de repaso

El contenido está **organizado por temas** usando carpetas `TEMA_1`, `TEMA_2`, etc., facilitando la navegación y el seguimiento progresivo del curso.

## 🚀 Cómo ejecutar las prácticas

Cada práctica incluye instrucciones en su propio `README.md`. Si no existe, busca la clase `main` o script principal.

### Primeros pasos (clonar el repositorio)
```bash
git clone https://github.com/IvnMD/DAM_Programacion1.git
cd DAM_Programacion1
```

### Ejecución por lenguaje

#### **Java (con Maven)**
```bash
cd TEMA_3/Proyecto0_Clases
mvn clean compile
mvn exec:java -Dexec.mainClass="es.tu.paquete.Main"
```

#### **Java (con Gradle)**
```bash
cd [carpeta-del-proyecto]
gradle build
gradle run
```

#### **Python**
```bash
python3 -m venv env
source env/bin/activate  # Linux/macOS
# o en Windows (PowerShell):
env\Scripts\activate
pip install -r requirements.txt
python main.py
```

#### **Node.js**
```bash
npm install
npm start
```
